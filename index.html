CORE CAPABILITIES

System Architecture

🧠

LangGraph Agent Brain

Stateful decision graph with cyclic tool invocation loops. Automatically routes requests between LLM reasoning, memory lookups, and system tools.

🕸️

GraphRAG Memory

Knowledge graph memory structure for contextual retrieval. Maintains entity relationships and cross-session knowledge across interactions.

🎙️

Low-Latency Audio

High-performance voice IO built with sounddevice and Whisper STT for 16kHz audio capture and instant speech synthesis.

👁️

Vision Grounding

Multimodal visual grounder capable of inspecting desktop screens, parsing spatial coordinates, and analyzing graphical UI elements in real time.

⚡

Local & Cloud LLMs

Seamless toggle between local privacy-first models (llama3.2:3b via Ollama) and cloud engines (gpt-4o-mini).

🛠️

Extensible Tool Suite

Equipped with system command execution, web search tools, memory indexing, and diagnostic sweeps for full autonomous operations.
