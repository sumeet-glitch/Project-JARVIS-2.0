# Project J.A.R.V.I.S. 2.0 🤖⚡

> Next-Generation Autonomous Multilingual Voice & Vision AI Assistant Powered by **LangGraph**, **GraphRAG Memory**, and Local LLMs.

---

## 🌟 Overview

**Project J.A.R.V.I.S. 2.0** is an autonomous AI assistant engineered with stateful decision-making graph loops, graph-based long-term memory retrieval, a multilingual voice pipeline (supporting Hindi, Hinglish, and English), and multimodal screen grounding vision.

---

## ⚡ Core Features

- **🧠 LangGraph Agent Brain:** Cyclic state graph architecture with automated ToolNode decision routing.
- **🕸️ GraphRAG Memory Engine:** Knowledge graph memory structures for entity relationship indexing across sessions.
- **🎙️ Multilingual Voice Pipeline:** Audio recognition & speech synthesis supporting **Hindi**, **Hinglish**, and **English** with Whisper STT and gTTS.
- **👁️ Multimodal Vision Grounding:** Screen capture analysis and spatial UI element grounding.
- **⚡ Local LLM Core:** Powered by local models (`qwen2.5:3b` / `llama3.2:3b` via Ollama).
